> 출처: 디자인 방향 시안 B 안정형(레이아웃) + 사용자 결정 "흑백 + 코랄 레드"(2026-11-25) + 사용자 결정 "부드러운 스타일 7원칙"(2026-11-25, v2).

> 요구사항의 기준은 PRD v1.5(Notion). 화면 규칙이 PRD와 충돌하면 PRD가 우선한다.

## 1. Visual Theme

**부드럽고(soft) · 넉넉하고(airy) · 정돈된(orderly) 굿즈 편집숍**

흰 바탕과 넉넉한 여백 위에 둥근 카드와 큰 사진을 올려 상품을 주인공으로 둔다. 강조 색은 코랄 레드 하나뿐이고, 나머지는 진하기가 다른 회색 단계로 위계를 만든다. 영역은 굵은 선 대신 옅은 그림자, 얇은 연회색 선, 회색 면으로 나눈다.

**7원칙 (v2, 사용자 결정)**
1. 넉넉한 여백: 요소 사이를 넓게 띄운다.
2. 둥근 모서리: 카드와 버튼 모서리를 둥글게.
3. 큰 제목: 제목 글자를 확실히 크게.
4. 포인트 색 하나: 강조 색은 코랄 한 가지만.
5. 옅은 그림자: 진한 테두리 대신 흐린 그림자.
6. 얇은 구분선: 굵은 선 대신 가는 연회색 선.
7. 회색 단계: 검정 하나 대신 진하기가 다른 회색.

레퍼런스(브랜드 요소는 쓰지 않고 특징만): 마플샵 — 사진 중심 넓은 그리드 / 애니플러스 샵 — 카테고리 탭 탐색, 신상·인기 섹션 구분 / 사용자 제공 상품 상세 레퍼런스 — 앱바·캐러셀·정보 칩·큰 상품명·큰 가격·하단 고정 버튼.

### 4.1 하이파이 시안 규칙 (6단계)
- 상품 이미지 자리: 실제 사진 전까지 placeholder 면 위에 상품군 선 그림(stroke만, gray-400–500). ProductCard는 `image` 슬롯(v2.1)으로 넣는다.
- 장바구니 행 가격: 줄 합계(가격 × 수량), 수량 2 이상이면 옆에 "(단가 × 수량)" 보조 글자.
- 주문 완료: 주문 상품을 모두 목록(썸네일·옵션·수량·줄 합계)으로 보여 줌. 주문한 장바구니 항목은 결제 성공 시 삭제되므로(PRD 7장 가정) 완료 화면 헤더의 장바구니 뱃지는 0(표시 안 함).
- 로그인 기본 시안: 장바구니 담기 중 로그인으로 온 경우의 '로그인 후 이어하기' Notice 표시.
- 홈: 카테고리 타일 오른쪽에 상품군 선 그림 아이콘 32, 배너 제목은 h2(헤더 로고가 h1).
- 상품 상세 배송 안내 예시 문구: "배송비 0원 / 모든 주문은 배송비 없이 보내 드립니다."(모바일·데스크톱 같은 문구로 맞춤)(D-10 고정 안내의 예시, 최종 문구는 개발 전 확정). 수량 상한 = 선택한 옵션 재고.
- 데스크톱(1280) 하이파이: 홈 배너는 12컬럼 안 3:1 면(radius 16, 글 2–6 · 그림 8–11컬럼, 제목 44) / 목록은 제목 44 + 상품 수(span 9)·정렬(span 3), 카드 4열 / 상세는 이미지 span 6(Carousel `rounded`)·정보 span 6, 상품명 30, 구매 버튼은 정보 영역 안 3+3(하단 고정 바 없음) / 장바구니·주문서는 제목 30, 목록·폼 span 8 + 주문 요약 span 4(흰 카드 shadow-sm, 위에 고정, 주요 버튼 포함) / 주문 완료 카드 span 6·로그인 카드 span 4 가운데, 제목 44 / 데스크톱 검색(D-Search: 제목 44 + SearchField L span 6 + 결과 줄·SortButton)·회원가입(D-Signup) 시안 있음.
- 관리자 하이파이: 필터 줄의 검색은 SearchField M(옆 선택 상자 48과 높이 맞춤). 표에 썸네일 40×50(radius 8), 재고 0은 품절 라벨, 판매 중지는 알약 라벨, 주문 이력 상품은 '삭제 불가'(비활성). 표 위 요약 "상품 N개 · 판매 중 n · 판매 중지 n", 대표 이미지에 '대표' 표시, 옵션 패널 제목 옆 '옵션 n개 · 총 재고 n'. 카테고리 화면의 삭제 규칙 안내는 Notice. 페이지 넘김: 관리자 상품 목록은 20개씩 페이지 넘김, 1차 사용자 목록·검색은 페이지 없이 전체 표시(가정, PRD v1.7). 카테고리 표는 정렬 순서 순(새 카테고리는 맨 뒤, 미분류는 항상 맨 뒤, 1차 순서 변경 UI 없음, 가정). 관리자 메뉴는 상품 관리 · 카테고리 관리 · 주문 관리(2차) · 대시보드(2차) 4개('회원 관리'는 PRD 기능이 없어 제거, 사용자 결정 PRD v1.7). 옵션 행 삭제: 주문 이력이 있는 옵션은 '삭제 불가'(비활성) + 재고 0으로 품절 처리 안내(A-04, 사용자 결정 PRD v1.7).
- 데스크톱 주문 흐름: 장바구니·주문서·주문 완료 제목 줄에 주문 단계 표시(장바구니 → 주문서 → 주문 완료, 현재 단계 강조). 주문서·완료는 주문 상품 전체 목록. 데스크톱 푸터는 정보 블록(로고·소개 / 카테고리 / 쇼핑 / 회원 / 이용 안내) + 선 + caption으로 모든 데스크톱 화면 공통. 회원가입은 로그인과 같은 가운데 카드(span 4).
- 예시 데이터 일관성: 키링 옵션은 크림 고양이(재고 12)·치즈 고양이(5)·검은 고양이(품절), 총 재고 17 — 상세·장바구니·주문·관리자 모두 같게.
- 약관 동의는 PRD·기능 명세서에 없어 주문서에 넣지 않음(추가하려면 범위 변경으로 사용자 확인).
- 데스크톱 탐색 보강: 목록·상세·검색에 브레드크럼(홈 / 카테고리 / 상품명). 홈 신상품 8개(2줄). 상세는 캐러셀 아래 썸네일 3개(현재 외곽선), '옵션 선택'·'배송 안내' 소제목, '상품 설명' 섹션(설명 + 상세 이미지 2장), '판매 정보' 회색 상자(카테고리·옵션 수·배송비·판매 상태). 상세 이미지는 관리자가 올린 상세 이미지(ERD ProductImage kind=DETAIL, A-03)를 쓴다. 재질·크기·구성 같은 상세 정보는 따로 표로 그리지 않고 상품 설명 글에 포함한다(1차, 사용자 결정 PRD v1.7).
- 상태 화면(하이파이) 문구·동작: 필수값 누락은 PRD대로 결제하기 비활성 + 바로 위 사유 문구, 칸을 벗어나면 빨간 테두리 + "연락처를 입력해 주세요." 등, 상단 요약 Notice(첫 오류 칸으로 이동 링크). 결제 직전 재고 부족은 주문서에 머물고 입력값 유지, 상단 Notice + 해당 상품에 "재고 부족 · 남은 수량 N개", 하단은 장바구니 경유 주문이면 '장바구니로 돌아가기', 바로 구매 주문이면 '상품으로 돌아가기'(상품 상세, 가정). 로그인 실패 "이메일 또는 비밀번호가 일치하지 않습니다."(비밀번호 칸 아래 한 번, 비밀번호 비움). 회원가입 중복 "이미 가입된 이메일입니다." + '이 이메일로 로그인하기 →', 비밀번호 확인 "비밀번호가 일치하지 않습니다.". 장바구니·주문서 오른쪽 패널 제목은 모두 '주문 요약'. 연락처는 입력 중 하이픈 자동 삽입(010-1234-5678), 저장은 숫자만(PRD v1.4). 회원가입 힌트 "숫자만 입력하면 하이픈이 자동으로 들어갑니다", placeholder "010-0000-0000".
- 빈 상태·예외 문구(하이파이 예시, PRD 7.10이 6단계로 미룬 문구): 검색 0건 "'키워드'에 맞는 상품이 없습니다" + 전체 상품 보기 / 빈 장바구니 "장바구니가 비어 있습니다" + 상품 보러 가기, 주문하기 비활성 + 사유 / 판매 중지 상세 "판매가 중지된 상품입니다. 장바구니에 담거나 바로 구매할 수 없습니다" / 관리자 상품 0개 "등록된 상품이 없습니다" + 상품 등록 / 판매 중 상품이 연결된 카테고리 삭제는 행 아래 안내 "삭제할 수 없습니다. 판매 중 상품 N개가 연결되어 있습니다…".
- 모바일 상태 화면: 빈 검색어는 SearchField `error`(v2.2.1)로 "검색어를 입력해 주세요"(PRD P-05). 검색 0건·카테고리 0건·빈 장바구니는 선 그림 아이콘 + EmptyState + 다음 행동 버튼. 품절·판매 중지 상세는 라벨 + Notice, 옵션 선택·구매 버튼 비활성 + 바로 위 이유 문구. 장바구니 구매 불가 항목은 항목마다 사유를 danger 글자로("재고 부족: …"/"품절"/"판매 중지"), 위에 요약 Notice, 주문하기 비활성 + 이유. 예상 결제 금액은 PRD O-02 공식대로 선택 항목 합계(구매 불가 항목 포함, 주문하기는 비활성). 하이파이에 '전체' 목록 화면이 없어 "전체 상품 보기"는 목록 화면으로 연결.
- 추가 상태 화면(PRD 7.10·4.2·7.3 근거, 1차 범위 — 사용자 결정, PRD v1.5): 상품 찾을 수 없음(홈으로 가기), 결제 서버 오류(입력값 유지 + 결제 다시 시도), 재고 초과 수량 선택 시 재고 수량으로 맞추고 안내, 관리자 입력 오류(재고 음수·이미지 업로드 실패, 입력값 유지).
- 관리자 접근 거부(A-01, PRD v1.3, 사용자 결정): 권한 없는 회원·비회원은 사용자 홈으로 이동하고 홈 맨 위에 Notice(live) "관리자만 들어갈 수 있는 페이지입니다"를 표시. 보조 문구는 회원·비회원 공통으로 "관리자 계정으로 로그인해야 쓸 수 있어 홈으로 이동했습니다." P3 정리: 구매 불가·품절·판매 중지 화면은 내용과 하단 바 사이 48만, 로그인 실패는 두 칸 모두 빨간 테두리(문구는 비밀번호 칸 아래 한 번, TextField `invalid`), 삭제 불가 안내는 1px danger 테두리, 관리자 빈 상태는 다음 행동 버튼 1개만.
- 컴포넌트 가이드(6-4): 고르는 법·카탈로그 26개·화면 패턴은 디자인 시스템 v2.3 README의 "컴포넌트 가이드". 7–8단계 컴포넌트화 후보: 관리자 헤더·메뉴, 주문 상품 행, 주문 단계 표시, 브레드크럼, 데스크톱 푸터, 상태 알약(Label pill 변형), 카테고리 타일. Chip은 1차 미사용(2차 필터용).

## 6. Depth

깊이는 **옅은 그림자 3단계 + 면 색**으로 표현한다. 진한 테두리는 쓰지 않는다.
| Level | 표현 | 사용처 |
|---|---|---|
| 0 | bg | 페이지 |
| 1 | surface 면(radius 16) 또는 `shadow-sm` | 주문 요약, 정보 칩, 카드, 보조 버튼, 입력 |
| 2 | `shadow-md` (0 4 20 / 8%) | 관리자 패널, 다이얼로그 |
| bar | `shadow-bar` (0 −4 20 / 6%) | 하단 고정 구매 바 |

## 7. Do's and Don'ts

### Do
- 요소 사이를 넓게 띄운다(섹션 48, 블록 32, 폼 필드 24).
- 카드·이미지 16, 버튼·입력 12로 둥글게 한다.
- 화면의 핵심 제목은 26–28(모바일)로 크게 한다.
- 코랄은 화면당 주요 행동 1개와 NEW 라벨, 장바구니 수량에만 쓴다.
- 영역은 옅은 그림자, 얇은 연회색 선, 회색 면으로 나눈다.
- 글자는 회색 단계로 위계를 만든다(제목 #111 · 본문 #333 · 보조 #5E5E5E).
- 오류는 색 + 문구(+ 입력 테두리)로 함께 알린다.
- 터치 대상 44×44 이상, 아이콘 버튼엔 aria-label.

### Don't
- 코랄 외 유채색을 추가하지 않는다.
- 1px 검정 테두리·굵은 선을 쓰지 않는다.
- 진한 그림자(불투명도 10% 초과), 그라데이션을 쓰지 않는다.
- #9E9E9E 이하로 옅은 회색을 텍스트에 쓰지 않는다.
- 1차 화면에 찜 버튼·하트 아이콘을 넣지 않는다(D-13). 리뷰·별점·할인율·공유도 1차 범위 밖.
- 사용자 화면의 카테고리 목록과 상품 등록·수정 선택지에 "미분류"를 노출하지 않는다(D-12, PRD 7.2). 관리자 조회 필터와 카테고리 관리 표의 시스템 행에는 보인다.

| mobile | < 768 | 헤더 아이콘형, 카테고리 탭 가로 스크롤, 상품 2열, 하단 고정 구매 바 |
| tablet | 768–1023 | 상품 3열, 헤더는 데스크톱형으로 전환 시작 |
| desktop | ≥ 1024 | max-width 1200, 상품 4열, 상품 상세는 이미지·정보 좌우 2단, 구매 버튼은 정보 영역 안 |
관리자 화면은 데스크톱 전용(1280 기준), 좁은 화면에서는 표를 가로 스크롤 상자에 넣는다.

## 9. Agent Prompt Guide

- 7원칙(1장)을 먼저 지킨다.
- 색은 위 토큰만 쓴다. 새 hex를 만들지 않는다. 유채색은 코랄 600/700뿐이다.
- 글꼴은 Noto Sans KR 하나, 제목은 800 + 자간 −2%, 크게.
- 모서리: 카드·이미지 16, 버튼·입력 12, 작은 상자 8, 칩·뱃지 알약형. 화면 끝에 붙는 헤더·바만 0.
- 그림자는 shadow-sm / shadow-md / shadow-bar 세 가지만.
- 간격은 4px 단위 스케일에서만 고른다.
- 화면을 만들 때 PRD 기능 ID와 결정(D-n)을 먼저 확인하고, 아트보드 이름에 기능 ID를 적는다.
- 아직 없는 값은 [가격], [상품명], [상품 이미지]처럼 대괄호 자리 표시로 둔다.
