삭제(A-02) 주문 이력 있는 상품은 비활성 "삭제 불가" + "주문 이력 있음", 판매 중지만 가능. 이력 없는 상품만 확인 후 삭제: "'[상품명]'을 삭제할까요? 되돌릴 수 없습니다." 미분류(D-12) 필터로 골라 봄. 판매 중으로 저장하면 "다른 카테고리로 먼저 변경하세요" 오류. 권한(A-01, D-1) 회원·비회원은 사용자 홈으로 이동, 관리자 API 거부.
빈 상태 상품 0건: "등록된 상품이 없습니다" + 상품 등록 · 필터 결과 0건: "조건에 맞는 상품이 없습니다" + 필터 초기화. 오류 상태 이미지 업로드 실패: 이미지 칸 아래 오류 문구 · 재고 0 미만: 그 칸 danger 테두리 + "재고는 0 이상" · 서버 오류: "다시 시도", 입력값 유지. 표는 6개 예시, 이후 페이지 넘김(가정).
