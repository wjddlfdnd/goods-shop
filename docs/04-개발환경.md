# 개발 환경 (7단계)

## 필요한 것
- Node.js 22 이상, npm 10
- PostgreSQL 16 — Docker가 있으면 `docker compose up -d db`, 없으면 직접 설치

## 처음 실행
```bash
cp .env.example .env          # DATABASE_URL, SESSION_SECRET 확인
docker compose up -d db        # 또는 로컬 PostgreSQL에 goodsshop DB 생성
npm install
npm run db:setup               # 마이그레이션 + 시드
npm run dev                    # http://localhost:3000
npm run smoke                  # 서버가 뜬 상태에서 기본 데이터 조회 확인
```

## 스크립트
| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` / `npm start` | 운영 빌드·실행 |
| `npm run db:migrate` | 개발 마이그레이션 생성·적용(`prisma migrate dev`) |
| `npm run db:seed` | 시드 데이터 다시 넣기(개발 DB를 비우고 채움) |
| `npm run db:setup` | 마이그레이션 적용 + 시드 |
| `npm run db:studio` | Prisma Studio(데이터 보기) |
| `npm run smoke` | `/api/health`·`/api/categories`·`/api/products`를 호출해 7단계 완료 기준 확인 |
| `npm run design:qa` | 디자인 캔버스 자동 QA(`design/qa`) |

## Git
- 기본 브랜치 `main`, 작업은 `feat/*`·`fix/*`·`docs/*` 브랜치 → PR → 병합.
- 커밋 메시지: `feat: 장바구니 담기 API` 처럼 종류 + 한국어 요약.
- `.env`, `src/generated/`, `public/uploads/`는 커밋하지 않는다.
