# 문서 동기화 장부 (LEDGER)

PRD·기능 명세서·DESIGN.md에 **없는 내용을 에이전트가 스스로 정한 것(가정)**, **문서끼리 안 맞는 것(불일치)**, **사용자가 대화로 정한 것(결정)**을 한 줄씩 쌓는 곳입니다.
`/doc-sync`가 상태가 `대기`인 줄을 읽어 Notion 문서(PRD, 기능 명세서, 05 회의·결정 기록, DESIGN)에 반영하고 상태를 `반영`으로 바꿉니다.

규칙
- 표 맨 아래에 한 줄 추가. 기존 줄은 수정하지 않는다(상태 칸은 /doc-sync만 바꾼다).
- 셀 안에 `|` 금지. 날짜는 YYYY-MM-DD.
- 종류: 가정 / 불일치 / 결정
- 대상 문서: PRD, 기능명세서, DESIGN, 와이어프레임 (여러 개면 `·`로 구분)
- 상태: 대기 / 반영(vX.Y) / 보류(사유) / 사용자확인
